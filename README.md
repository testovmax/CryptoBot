# 🤖 КриптоБот - Telegram бот для отслеживания криптовалют

## ✨ Возможности

- 📊 **Отслеживание курсов** - Просмотр актуальных цен криптовалют
- 💱 **Конвертация валют** - Перевод между различными криптовалютами
- 🔔 **Ценовые оповещения** - Уведомления при достижении целевой цены
- 📈 **Статистика** - Отслеживание активности пользователей
- 🌍 **Мультивалютность** - Отображение цен в разных валютах (USD, RUB, EUR, KZT, UAH)
- ⚡ **Автообновление** - Автоматическое обновление цен каждую минуту

## 💰 Поддерживаемые криптовалюты

Бот поддерживает следующие криптовалюты:

- **BTC** - Bitcoin
- **ETH** - Ethereum
- **BNB** - Binance Coin
- **SOL** - Solana
- **LTC** - Litecoin
- **LINK** - Chainlink

## 🔧 Требования

- **C++17** или выше
- **CMake** версии 3.10 или выше
- **Компилятор** с поддержкой C++17 (GCC, Clang, MSVC)
- **curl** - для работы с Telegram API
- **Токен Telegram бота** - получить у [@BotFather](https://t.me/BotFather)

## 📦 Установка и сборка

### Linux/macOS

```bash
# Клонируйте репозиторий или перейдите в директорию проекта
cd CryptoBot

# Создайте директорию для сборки
mkdir build
cd build

# Настройте проект с помощью CMake
cmake ..

# Соберите проект
make

# Исполняемый файл будет в директории build
```

### Windows (WSL/MinGW)

```bash
# В WSL или Git Bash
cd CryptoBot
mkdir build
cd build
cmake ..
cmake --build .
```

### Очистка сборки

```bash
cd build
make clean
# или
rm -rf build/*
```

## ⚙️ Настройка

### Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

### Сохранение токена

При первом запуске бот попросит ввести токен. Токен будет автоматически сохранен в файл `bot_token.txt` в директории `build/` для последующих запусков.

## 🚀 Запуск

```bash
cd build
./crypto_bot
```

При первом запуске:
1. Введите токен бота (или он будет прочитан из `bot_token.txt`)
2. Дождитесь сообщения "✅ Подключение к Telegram успешно"
3. Бот готов к работе!

Для остановки бота нажмите `Ctrl+C` в терминале.

## 🔍 Технические детали

### Архитектура

- **CryptoBot** - Главный класс, координирующий работу всех компонентов
- **CurrencyManager** - Управление данными о криптовалютах и их ценах
- **UserManager** - Управление пользователями и их статистикой
- **TelegramHandler** - Обработка взаимодействия с Telegram API
- **HistoryLogger** - Логирование действий пользователей

### Особенности реализации

- **Потокобезопасность**: Использование `std::mutex` для защиты общих данных
- **Автообновление цен**: Цены обновляются автоматически каждую минуту
- **Проверка оповещений**: Оповещения проверяются каждые 30 секунд
- **Мок-данные**: Используются симулированные цены с небольшими случайными колебаниями
- **URL-кодирование**: Безопасная передача данных в Telegram API

### Автоматические задачи

Бот автоматически выполняет следующие задачи:
- Обновление цен криптовалют каждую минуту
- Проверка срабатывания оповещений каждые 30 секунд
- Отправка уведомлений при срабатывании оповещений

### Формат данных

- **Цены**: Отображаются в USD с точностью до 2 знаков после запятой (для цен > $1) или 4 знаков (для цен < $1)
- **Изменение за 24ч**: Процентное изменение с точностью до 2 знаков
- **Время обновления**: Формат HH:MM:SS

## 🐛 Решение проблем

### Бот не запускается

1. Проверьте, что токен бота введен правильно
2. Убедитесь, что у вас есть интернет-соединение
3. Проверьте, что `curl` установлен и доступен в системе

### Бот не отвечает на команды

1. Убедитесь, что бот запущен и работает
2. Проверьте подключение к интернету
3. Убедитесь, что вы используете правильные команды (см. `/help`)

### Ошибки компиляции

1. Убедитесь, что используется C++17 или выше
2. Проверьте, что все зависимости установлены
3. Попробуйте очистить сборку: `cd build && make clean && cmake .. && make`
