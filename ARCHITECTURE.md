# Архитектура и реализация CryptoBot

Этот документ описывает **внутреннюю структуру** бота, принципы проектирования, потоки выполнения и ключевые решения.

---

## 🧱 Общая архитектура

CryptoBot построен по **модульному принципу**:
+-----------------+ | main.cpp | → Точка входа, запуск +-----------------+ ↓ +-----------------+ | CryptoBot | → Основной класс, управляет логикой +-----------------+ ↓ ↓ ↓ +-----------+ +------------------+ +------------------+ | Telegram | | CurrencyManager | | UserManager | +-----------+ +------------------+ +------------------+


Каждый модуль:
- Инкапсулирует свою логику
- Обеспечивает потокобезопасность
- Использует RAII и STL

---

## 🧩 Основные классы

### 1. `CryptoBot`
**Назначение**: Главный контроллер приложения  
**Отвечает за**:
- Запуск цикла обработки сообщений
- Вызов фоновых задач (`autoTasks`)
- Обработку сигналов (`SIGINT`, `SIGTERM`)
- Сохранение и загрузку состояния (`state.json`)

**Ключевые методы**:
- `run()` — основной цикл
- `processMessages()` — обработка команд
- `autoTasks()` — проверка алертов, обновление цен
- `saveState()` / `loadState()` — сериализация

---

### 2. `TelegramHandler`
**Назначение**: Взаимодействие с Telegram Bot API  
**Принцип работы**:
- Использует `curl` через `popen()` для отправки/получения сообщений
- Не зависит от внешних библиотек (кроме `json.hpp`)
- Парсит `getUpdates` с помощью `nlohmann::json`

**Методы**:
- `getMessages()` — получает новые сообщения
- `sendMessage()` — отправляет текст
- `execCommand()` — универсальный вызов `curl`

> ⚠️ Альтернатива: использование `libcurl` в будущем для повышения производительности.

---

### 3. `CurrencyManager`
**Назначение**: Управление ценами криптовалют  
**Источник данных**: [CoinGecko API](https://www.coingecko.com/api)  
**Обновление**: Каждые 10 секунд

**Особенности**:
- Реальные цены: `BTC`, `ETH`, `BNB`, `SOL`, `LTC`, `LINK`
- Поддержка 24h изменения
- Конвертер: между криптовалютами и фиатом (USD, RUB, EUR, KZT)

**Ключевые методы**:
- `updatePrices()` — получает данные с CoinGecko
- `formatCurrencyInfo()` — формирует красивый ответ
- `formatConversion()` — конвертация

---

### 4. `UserManager`
**Назначение**: Управление пользователями и статистикой  
**Функции**:
- Регистрация пользователей по `userId`
- Счётчик команд
- Избранные валюты
- Потокобезопасность через `std::mutex`

**Важно**: `users` — приватное поле, доступ только через методы.

## 🔄 Потоки выполнения

### Основной поток (`main` → `CryptoBot::run`)
```cpp
while (!stopRequested) {
    processMessages();    // Проверяет новые сообщения
    autoTasks();          // Фоновые задачи: обновить цены, проверить алерты
    sleep(100ms);
}
autoTasks() — фоновые операции
cpp
void autoTasks() {
    if (10 сек прошло) → updatePrices()
    checkAlerts() → если цена достигла цели → отправить уведомление
}
processMessages()
Получает сообщения через TelegramHandler::getMessages()
Парсит команды: /start, /price, /alert
Вызывает нужный обработчик
Отправляет ответ
💾 Сохранение состояния (state.json)
Формат:
json
{
  "alerts": [ { "userId": 989793322, "crypto": "BTC", ... } ],
  "users": { "989793322": { "username": "testov_max", ... } }
}
Жизненный цикл:
При старте: loadState() → восстанавливает алерты и пользователей
При работе: изменения в памяти
При остановке: saveState() → сохраняет в state.json
Важно: Алерты удаляются после срабатывания → не сохраняются.

🔐 Потокобезопасность
Все классы используют мьютексы:

| Класс | Мьютекс | Защищает | |------|--------|--------| | UserManager | mutable std::mutex mutex | users | | CurrencyManager | mutable std::mutex mutex | currencies | | CryptoBot | mutable std::mutex alertsMutex | alerts |

Используется std::lock_guard → автоматическое освобождение.

🧪 Обработка ошибок
| Ситуация | Реакция | |--------|--------| | Ошибка парсинга JSON | Игнорируется, бот продолжает работать | | CoinGecko недоступен | Остается на последних известных ценах | | curl не найден | execCommand возвращает пусто → безопасно | | Некорректная команда | Ответ: Используй /help |

🧰 Используемые технологии
| Технология | Назначение | |----------|----------| | C++17 | Язык | | CMake | Сборка | | nlohmann/json.hpp | Парсинг/сериализация JSON | | popen + curl | HTTP-запросы (без внешних зависимостей) | | std::thread, std::mutex | Многопоточность | | std::unique_ptr | Умные указатели для popen/pclose |
